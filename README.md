# What's For Dinner

What's For Dinner is a responsive recipe web application that helps users discover delicious meals from different cuisines around the world.

## Features

- Browse multiple recipes
- Generate a random recipe
- View ratings and reviews
- Display ingredients and cooking instructions
- Nutrition facts
- Chef's tips
- Preparation and cooking time
- Fully responsive design for desktop, tablet, and mobile

## Built With

- HTML5
- CSS3
- Bootstrap 5
- JavaScript (ES6)
- Font Awesome

## Future Improvements

- Search recipes
- Filter by category
- Favorite recipes
- Local Storage support
- API integration
